# RealMojiリアクション仕様

## 目的

友達の寝起き写真に、その場で撮影した顔写真でリアクションできるようにする。

このブランチのユーザー向けリアクションはRealMojiの1系統だけとする。既存の`😂`リアクションは画面から使用しないが、`photo_reactions`テーブル、SQL、サービスと既存データは削除しない。

## 選択できる表情

| 絵文字 | 表示名       |
| ------ | ------------ |
| 😂     | 爆笑         |
| 🤣     | 大爆笑       |
| 😏     | ニヤニヤ     |
| 🙄     | はいはい     |
| 😜     | ざんねん     |
| 🥱     | まだ眠いの？ |

## 操作フロー

1. フィードまたは投稿詳細で「顔で返す」を押す。
2. 一覧から表情を選ぶ。
3. カメラ権限を許可し、インカメラで顔写真を撮影する。
4. プレビューで「撮り直す」または「送信」を選ぶ。
5. 送信したRealMojiは投稿下に丸い顔写真と絵文字で表示する。
6. RealMojiの一覧を押すと、送信者と送信時刻を確認できる。

## ルール

- 1ユーザーが1投稿に送れるRealMojiは1件。
- 送信済みの投稿で再度撮影すると、既存のRealMojiを差し替える。
- 自分のRealMojiは削除できる。
- 他の投稿で使うための顔写真保存・再利用機能は持たない。
- Instant RealMoji、アンロック、写真ライブラリからの選択は持たない。
- 起床チャレンジ用の顔検出はRealMoji撮影には適用しない。
- 自分の投稿へのRealMoji送信はDBポリシーで拒否する。

## 保存先

### `photo_realmojis`

| カラム         | 用途                                   |
| ---------------- | -------------------------------------- |
| `id`             | RealMoji ID                            |
| `photo_id`       | 対象の寝起き写真                         |
| `profile_id`     | 送信者                                 |
| `emoji`          | 選択した表情                             |
| `storage_path`   | 非公開Storage内のパス                  |
| `created_at`     | 初回送信日時                           |
| `updated_at`     | 最終差し替え日時                       |

`(photo_id, profile_id)`はユニークとする。

### `realmoji-photos` Storage

- バケットは非公開。
- パスは`{profileId}/{photoId}/{uniqueName}.jpg`。
- 表示時に1時間有効の署名付きURLを生成する。
- 差し替えと削除時に古いStorageオブジェクトを削除する。

## Supabaseへの適用

Supabase DashboardのSQL Editorで`supabase/sql/2026-08-23_photo_realmojis.sql`を実行する。

SQLは以下を作成する。

- `photo_realmojis`テーブル
- 友達関係と投稿所有者を基準にしたRLSポリシー
- 非公開`realmoji-photos`バケット
- RealMoji顔写真の参照・追加・削除ポリシー

適用後、友達ユーザーで次を確認する。

1. 各表情を選択できる。
2. カメラを拒否したとき、エラー表示後もフィードを操作できる。
3. 撮り直しで写真が上書きされる。
4. 送信後に顔写真と絵文字が表示される。
5. プルリフレッシュ後もRealMojiが残る。
6. 差し替えと削除が反映される。
7. 既存の`photo_reactions`行が変更・削除されていない。
